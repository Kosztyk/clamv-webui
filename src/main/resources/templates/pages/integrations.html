Connection details and Grafana setup

The metrics listener uses port . ClamD telemetry is sampled every seconds. Use your HTTPS proxy hostname or a protected management listener for the scrape URL.

Listener ports and the telemetry sampling interval are container settings: MANAGEMENT_SERVER_PORT and CLAMAV_METRICS_CLAMD_POLL_MS. Recreate the Web UI after changing them. Disabling scraping here does not stop the internal telemetry overview.

curl --fail --cacert /path/to/lab-ca.crt \
  -H "Authorization: Bearer $CLAMAV_METRICS_TOKEN" \
  https://YOUR_WEB_UI_HOST/actuator/prometheus

Expect Prometheus text containing clamav_queue_items and clamav_threads_live. Scan counters appear after the first matching scan. A browser login or API token does not authorize a scrape.

Command line · clamctl

Runs on your computer

No Web UI switch is required. Install the matching binary from cli/dist and create an API token with only the needed scopes.

clamctl config set-server https://YOUR_WEB_UI_HOST
clamctl login --token-stdin < /secure/api-token
clamctl status --json
clamctl scan upload ./sample.txt --wait --json

For LDAP or OIDC users, create a token after signing in through the browser. The CLI uses that token; it does not perform an interactive LDAP or SSO login.

AI assistants · MCP

Separate clamctl process

Start the MCP server on the host holding the files your assistant will scan. An upload root grants access only to that directory.

clamctl mcp serve --upload-root /path/to/lab-files

Expose five tools and three resources through stdio. Optional HTTP uses a separate Bearer token and a TLS proxy. Stop the process to disable it; revoke its API token to block access to this Web UI.

A server-side toggle cannot start a process on your laptop. HTTP clients that require OAuth need a compatible gateway.
