Advanced: configuration precedence
    
Discovery and precedence

    
Automatic discovery: .

    
An explicit host or port override controls the endpoint connection.

    
An explicit clamd.conf path enables synchronization unless CLAMAV_CONFIG_DISCOVERY_ENABLED=false. LocalSocket takes priority over TCP settings; mount the socket at the same path. Wildcard TCP addresses use loopback. Other named endpoints retain their settings.

    
Mount configuration files read-only using CLAMAV_CONFIG_PATH and FRESHCLAM_CONFIG_PATH. Metrics are protected by a separate bearer scrape token and are not shown on this page to non-administrators.
