Start here

For a remote ClamD server, configuration files can be unavailable and scans can still work normally. First check the live connection and definition age below. File observation is optional.

Changing a file here does not reload ClamD. Restart or reload the daemon separately after changing its own configuration.

File observation controls

Leave inheritance off for inspection only. Disabling it removes the additional file-based limits; the normal application scan policy still applies. Only the endpoint named default can be synchronized.

The container sets CLAMAV_HOST or CLAMAV_PORT, so it keeps control of the connection address. File-based scan limits and exclusions can still be inherited.

File paths are selected by the container environment and read-only mounts. A browser cannot mount files from your server.

Home-lab testing guide
How to mount configuration files

Mount the ClamD host's actual configuration directory read-only. These paths are examples; use the directory used by your daemon.

environment:
  CLAMAV_CONFIG_PATH: /daemon-config/clamd.conf
  FRESHCLAM_CONFIG_PATH: /daemon-config/freshclam.conf
volumes:
  - /YOUR/HOST/CLAMAV/CONFIG:/daemon-config:ro

Recreate the Web UI container after changing mounts or environment variables. If LocalSocket is configured, its socket must also be mounted at the same absolute path. A config file alone does not grant access to a remote socket.

Connection
Available should be Yes. If No, check the endpoint address, network and daemon service.

Definition age
Check that definitions are updating. A rising age can mean freshclam cannot reach its update source.

Queue & busy threads
Short spikes are normal. A queue that keeps growing with all threads busy suggests sustained saturation.

Discovery and precedence

    
Automatic discovery: .

    
An explicit host or port override controls the endpoint connection.

    
An explicit clamd.conf path enables synchronization unless CLAMAV_CONFIG_DISCOVERY_ENABLED=false. LocalSocket takes priority over TCP settings; mount the socket at the same path. Wildcard TCP addresses use loopback. Other named endpoints retain their settings.

    
Mount configuration files read-only using CLAMAV_CONFIG_PATH and FRESHCLAM_CONFIG_PATH. Metrics are protected by a separate bearer scrape token and are not shown on this page to non-administrators.
