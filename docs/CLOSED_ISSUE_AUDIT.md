# ClamAV Web UI 2.1.0 closed-issue audit

Reviewed the uploaded full-source archive against all 57 GitHub issues numbered [#1 through #57](https://github.com/Kosztyk/clamv-webui/issues?q=is%3Aissue+state%3Aclosed) and the open pull request [#81](https://github.com/Kosztyk/clamv-webui/pull/81). The ZIP keeps the Maven and application version at `2.1.0`.

## Findings and changes

- The uploaded ZIP predates GitHub `main` at `d09409a71a01a01022ed23ce54badd44758324f9`. The audit incorporates the subsequent PostgreSQL V9 compatibility and migration-fixture changes, Configuration Center changes, CI fixes, and release documentation. It also restores executable modes from Git for the affected scripts. [GitHub main revision](https://github.com/Kosztyk/clamv-webui/commit/d09409a71a01a01022ed23ce54badd44758324f9)
- The ZIP includes PR #81's conditional coverage comparison. The workflow reports a Git diff error as a job failure, and the new tests exercise the actual workflow step in temporary Git repositories. Both Maven test runs and static analysis remain blocking on full CI. The candidate's minimum is **82%**. When application or Maven inputs change, the relative comparison fails on a drop greater than **0.01 percentage point**. Integration timing can still affect a comparison on an application change. [Coverage and upgrade guide](QUEUE_COVERAGE_UPGRADE_HARDENING.md)
- The CLI, MCP, Docker, and identity guides now agree on the actual settings for TLS-terminating proxies. Direct access ignores forwarded headers by default. A TLS-terminating proxy uses `native` and an explicit peer allowlist. [Proxy TLS guide](REVERSE_PROXY_TLS.md)
- The first full CI run for PR #81 completed **26 of 26 jobs successfully** at `c13b23b28f26a893b0562b7a79271d8dd8b072da`. These included Java 21/25, Java quality, four database engines (H2 in Java verification, PostgreSQL/MySQL/MariaDB in the database matrix), H2 and PostgreSQL live upgrades, Docker smoke, browser, the CLI platform matrix and integration, API contract, and security jobs. The candidate and baseline builds in `java-quality` passed. The relative coverage step was inapplicable on this CI-only revision. Application and test files in the ZIP match that revision. The ZIP's workflow refinements were checked locally. [Full PR CI run](https://github.com/Kosztyk/clamv-webui/actions/runs/45055371545)
- The active ruleset for `main` requires pull requests and the up-to-date `gate` check, blocks deletion and force pushes, and has no bypass actors. Before the audited refresh, the scheduled run passed all 26 jobs. The earlier push-triggered run failed at the relative coverage comparison addressed by #81. [Ruleset](https://github.com/Kosztyk/clamv-webui/rules/27534708) · [Scheduled run](https://github.com/Kosztyk/clamv-webui/actions/runs/45196805231) · [Push run](https://github.com/Kosztyk/clamv-webui/actions/runs/45054560337)
- The versioned source includes tag-triggered verification, signing, and draft publication. The one-time publisher created the original `v2.1.0` release without attached assets. At audit time, public GHCR access and the private vulnerability reporting setting were unverified. The release page lists the downloads available for this version. [Publication run](https://github.com/Kosztyk/clamv-webui/actions/runs/45042026915) · [Published release](https://github.com/Kosztyk/clamv-webui/releases/tag/v2.1.0) · [Release runbook](../RELEASE.md)

## Local checks

- The static release gate, issue-specific source checks, standalone Java checks, actionlint, and version check for `v2.1.0` passed.
- `go vet ./...` and `go test -race ./...` passed with Go 1.26.11. Two builds produced identical checksums for all six CLI targets with version `2.1.0`.
- The H2 startup query check used the shipped V1 and V5 SQL and 140 queued rows plus one interrupted row. Adding one million completed jobs left the same H2 index scan count of 142 and the same 100-ID result limit.
- The full Java, Docker, and live database-upgrade results come from the linked GitHub Actions run. Local Maven dependency resolution remained incomplete.
